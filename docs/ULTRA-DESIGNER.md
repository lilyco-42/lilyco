# Ultra 原型设计器

> Axure 式拖拽原型：左侧组件库拖到画布，拖/缩/对齐/图层/属性，右侧实时预览，一键导出 React。
> 设计器本身**零依赖、零外链**；产物复用 `spec → generator`，不是另造渲染器。

```bash
LILYCO_UI=ultra LILYCO_PORT=8090 cargo run -p <你的载体>
# 打开 http://127.0.0.1:8090/designer
```

## 1. 界面

```text
┌────────┬──────────────────────────┬─────────────┐
│ 组件库  │  画布（1200×900，8px 网格） │  属性 / 图层 │
└────────┴──────────────────────────┴─────────────┘
```

| 区域 | 作用 |
|---|---|
| 组件库 | 13 种组件，拖到画布或点击添加 |
| 画布 | 绝对定位；拖动、右下角缩放、框选、对齐参考线 |
| 属性 | 文本、X/Y、宽高、颜色（按类型显示文本字段） |
| 图层 | 元素列表，↑/↓ 调整叠放顺序 |

## 2. 组件（13 种）

| 类型 | 默认 props | 尺寸 |
|---|---|---|

| 按钮 | `{文本, 动作, 样式}` | 120×44 |
| 输入框 | `{标签, 变量, 占位符}` | 260×66 |
| 数字框 | `{标签, 变量, 默认}` | 260×66 |

| 文本域 | `{标签, 变量, 行数}` | 260×100 |

| 分隔线 | `{}` | 260×12 |

| 计算器 | `{变量, 模式}` | 220×60 |

## 3. 交互

| 操作 | 行为 |
|---|---|
| 从组件库拖到画布 | 在落点创建元素，坐标吸附 8px |
| 点击组件库 | 顺序追加（不拖也能加） |
| 拖动元素 | 移动全部选中项；与其它元素 x/y 差 <8px 时吸附并画参考线 |
| 右下角小方块 | 缩放，最小 40×24，8px 步进 |
| 空白拖拽 | 框选（与元素相交即选中） |
| Shift + 点击 | 加选 |
| 属性面板 | 改文本 / X / Y / 宽 / 高 / 颜色，预览同步 |
| 图层面板 ↑/↓ | 调整 `elements` 数组顺序（决定叠放） |
| 撤销 / 重做 | 快照栈（≤80） |
| 预览 | 右侧全屏 iframe，实时反映当前设计 |
| 画布缩放 | 顶栏 `－ / 100% / ＋ / 适应`，`transform: scale()`；滚动仍由外层容器负责 |
| 导入 JSON | 顶栏「导入 JSON」选文件，等价 `importJson(text)` |
| 导出 HTML | 后端转 UiSpec → `generator` → React 页面 |
| 导出 JSON | 下载 `prototype.design.json`（可用「导入 JSON」再打开） |

快捷键：`Delete` 删除选中，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。

## 4. 数据格式（唯一契约）

设计稿（`~/.lilyco/designer.json`）：

```json
{
  "title": "Lilyco 原型",
  "size": "medium",
  "elements": [
    { "id": "按钮1", "type": "按钮", "x": 24, "y": 32, "w": 120, "h": 44,
      "color": "#2563eb", "props": { "文本": "确定", "动作": "ok", "样式": "primary" } }
  ]
}
```

导出时转成 UiSpec 的绝对定位模式（`布局: "absolute"` + `位置[]`），流式 JSON 仍完全兼容：

```json
{ "窗口": { "标题": "…", "大小": "medium", "布局": "absolute",
  "元素": [{ "类型": "按钮", "文本": "确定", "动作": "ok", "样式": "primary" }],
  "位置": [{ "x": 24, "y": 32, "w": 120, "h": 44, "color": "#2563eb" }] } }
```

## 5. API

| 路由 | 作用 |
|---|---|
| `GET /designer` | 设计器页面 |
| `POST /api/designer/save` | 保存 DesignDoc 到 `~/.lilyco/designer.json` |
| `GET /api/designer/load` | 读取（404 = 尚无保存） |
| `POST /api/designer/export` | 返回 `{ ok, spec, html }`，`html` 为 React 页面 |

## 6. 实测（CDP，20 项全 PASS）

```text
页面 200；外部请求 0、失败 0
组件库 13；拖入后 elements=1
拖动 200,160 → 320,224（8px 吸附）
缩放 120×44 → 160×80
对齐：y 差 4px 触发；12px 不触发
框选 selected=2；图层上移 a1,b1 → b1,a1
属性改文本/宽/颜色；预览 iframe 同步
撤销/重做、保存/加载、刷新恢复
导出 HTML 8408B（含 ReactDOM.createRoot + absolute）
```

Rust 侧：`cargo test -p lilyco-ultra-ui` 输出 17 + 3 + 12 passed（设计器 4 项：转换、JSON 键、错误定位、空稿）。

## 7. 已知限制

- **headless 下 CDP 键盘不可达**（`hits=0`）：`Delete` / `Ctrl+Z` 的快捷键在真实浏览器验证；自动化审计改用页面内等价调用（`undo/redo`、`KeyboardEvent`），并已在此注明。
- **对齐参考线**：`snap()` 命中时把线写入 DOM（`.align`），松手清除；headless 审计里「吸附与计数」稳定 PASS，「线的 DOM 存在」未稳定断言（`alignHits` 1 / `dom` 0），需在真实浏览器目检。
- 导出的 React 页面按既有设计引 `unpkg` 的 React 18 + Babel（带 SRI）；**设计器页面本身零外链**。
- 预览使用设计器本地渲染，与导出的 React 产物在细节样式上可能略有差异（结构一致）。
- 旧 `/`、`/graph`、`/api/render`、`/api/validate` 已回归：均 200（builder 页仍含 Excel 文案）。

API Documentation · OpenAI & Anthropic Compatible

API 调用文档 · 一分钟接入

一把 lkr_... 密钥同时支持 OpenAI 协议（/relay/v1）与 Anthropic Claude Code 协议（/relay，不带 /v1）。

1. OpenAI 兼容对话补全（curl）

curl https://api.lain42.top/relay/v1/chat/completions \
  -H "Authorization: Bearer lkr_你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wb-cn:glm-5.3",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": true
  }'

2. Anthropic / Claude Code 兼容

注意：Anthropic 客户端的 base_url 不要带 /v1。

export ANTHROPIC_BASE_URL="https://api.lain42.top/relay"
export ANTHROPIC_AUTH_TOKEN="lkr_你的密钥"
claude

3. 图像生成（志愿者算力队列）

curl https://api.lain42.top/relay/v1/images/generations \
  -H "Authorization: Bearer lkr_你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "img:flux-pro-volunteer",
    "prompt": "clean minimal product photo"
  }'

4. AI Agent / MCP 原生接入本站

本站由 Lilyco 框架驱动，直接暴露机器可读协议供 Agent 自动发现与调用：

GET  /llms.txt
GET  /.well-known/agent.json
GET  /openapi.json
POST /mcp  (JSON-RPC 2.0)

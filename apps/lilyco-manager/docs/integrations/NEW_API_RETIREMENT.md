## 架构
- Canvas（前端）与管理后台独立部署。
- Rust Gateway 负责认证、模型能力目录、配额、请求幂等、限流、用量审计和流式转发。
- Studio Billing 仅接受服务端授权的计费与权益调用；绝不允许浏览器直接调用管理员接口。
- SQLite/SeaORM 用于本地管理；多实例资金与订单系统使用可靠事务数据库和幂等消息处理。
- 视频生成采用异步 job、最大并发/每日预算、重试上限和状态恢复，防止重复花费。

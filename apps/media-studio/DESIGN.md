# 视频工坊

复用原 lffmpeg 的本机桌面工具，不做在线营销页或第二个编码器。

- 官方 shadcn base-vega 组件及 MIT 原文保持只读，来源摘要随 UI 保存；业务样式使用中性背景、克制绿色主操作与统一深浅语义 tokens。
- Lyco 原创透明源图与独立 IP 许可随产品保留，不分发角色设计基准图。字体自托管 Noto Sans SC，不能只靠 DOM 中文来证明字形可读。
- 压缩、格式、尺寸、片段四个明确目标；展示真实文件信息和引擎进度，未知比例显示不确定状态，不承诺固定压缩率。
- 原件、成果与设置分区，320 px 单列，键盘可选文件/修改参数/取消/下载；长文件名和 JSON 不撑宽窗口。
- 新文件或参数变更清除旧成果，断线保留未知运行状态继续查询，禁止误报成功或让同一文件悄悄并发运行。
- 临时文件、执行与导出都在本机；不能提交任意命令、工具路径或输出路径。删除文件会取消其任务，关闭宿主清理临时工作区。
- 产品构建、真实转码/解码、响应式、原生 WebView2、安装和许可证载荷验收全部在 GitHub Actions。未通过完整门禁不发行，不把初版当成已售桌面包。

# lilyco office · 文档透视

本机文档工作台，不是营销页。一个文件、一个问题、一次真实读取。

- 使用既有官方 base-vega shadcn button/card/badge/separator 原文，组件源及 MIT 许可只读；定制位于业务组件和语义 tokens。
- 沿用素材工坊的中性背景与克制绿色主操作，支持深浅主题，系统 CJK 字体，主要文案行高 1.75，操作命中区至少 40–44 px。
- 桌面为工具导航 + 文件动作 + 结构结果；320 px 下单列，工具双列，长文件名/路径/JSON不横向撑开窗口。
- 小于640px时文件说明、选择按钮及读取动作分行；图标不收缩。真实原生门另查中文标题可用宽度、按钮在说明下方和40px命中区，不用无横向溢出代替可读性。
- 新文件或新读取必须清除旧结果，失败不能留下上一份文件的答案。读取期间不能切换参数、文件或清理工作区。
- 最近文件仅在窗口内存保留，最多八个，可逐条/全部移除。只持久化主题。
- 展示原 CLI 返回字段，不凭字段名字补事实；数组分批显示，原始 JSON与复制保留全部结果。不给未实现的编辑、转换、进度百分比或取消按钮。
- 文件选择使用官方 Tauri dialog；拖入监听本窗口事件，IPC只调用原只读白名单。宏不执行，不发送文件或 Cookie。
- 所有类型检查、真实 CLI 浏览器往返、原生 Tauri IPC、响应式/键盘和打包测试只在 Actions。
